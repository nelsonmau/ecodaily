# EcoDaily: sito

Questo repository contiene solo il sito pubblico di EcoDaily, generato automaticamente
da un altro repository (privato) a ogni edizione. Non modificare i file a mano: vengono riscritti.

EcoDaily non è una testata giornalistica: è un progetto sperimentale di automazione con
l'intelligenza artificiale, curato da Andrea Nelson Mauro (nelson@ondata.it).
